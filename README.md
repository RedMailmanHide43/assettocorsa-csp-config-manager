## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Weather Settings** | Configure CSP weather and lighting options visually |
| **Physics Tweaks** | Adjust CSP physics extension settings per car or globally |
| **Profile System** | Save named CSP configurations for different racing scenarios |
| **Car Features** | Enable or disable per-car CSP features from a single interface |
